# Challenges
Merge sorting came as a challenge for me to understand compared to insertion sorting. While insertion sorting is essentially moving a bunch of differently sized blocks around until they end up being in ascending order, Merge sorting dissassembles the whole pile of blocks and sorts them by putting them together until they return as a row of blocks in ascending order. The code for merge sorting looks a lot more sophisticated than insertion sorting.
